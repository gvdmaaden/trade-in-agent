# trade-in-agent

Een AI-agent voor trade-in: automatisch inruilwaardes bepalen, offertes opstellen en klantvragen afhandelen.

## 🚀 Features

- Inruilwaarde-inschatting op basis van productgegevens
- Geautomatiseerde offerte-generatie
- Integratie met bestaande systemen (API)

## 📦 Installatie

```bash
git clone https://github.com/gvdmaaden/trade-in-agent.git
cd trade-in-agent
```
